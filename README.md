# The Weeknd — In the Grass

Live website: https://global0809.github.io/weeknd-in-the-grass/

Independent creative concept with reactive grass, nine eras and 27 music previews.

Run `npm ci` then `npm run build`. GitHub Pages serves the committed `docs/` directory from `main`. Run `npm run dev` for local development.

See SOURCE-NOTICES.md for artwork, reference and font credits.
